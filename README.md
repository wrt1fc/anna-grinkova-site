# Сайт Анны Гриньковой

Адаптивный дизайн сайта с открытыми фрагментами карты дня и прогноза на неделю. Основной вариант — редакционная страница с фотографиями Анны, личным разделом и переходом к полному чтению.

## Запуск

Сайт сделан на HTML, CSS и JavaScript без сборки. Из корня проекта:

```powershell
python -m http.server 4173 --directory prototype
```

Откройте `http://localhost:4173`.

## Состав

- `prototype/` — сайт и его исходные изображения.
- `design/svg/variant-1-*.svg` — четыре экрана для импорта в Figma.
- `design/svg/institute-emblem-gold.svg` — векторная эмблема Института.
- `design/preview/` и `design/variant-1-svg.zip` — изображения для просмотра и архив SVG.
- `PRODUCT.md` и `DESIGN.md` — продуктовые и визуальные решения.

Вертикальный и горизонтальный портреты предоставлены заказчиком. Их исходники сохранены в `prototype/assets/`, а версии с тёплым тёмным фоном используются на сайте и в SVG. Эмблема и декоративные изображения подготовлены по фирменным материалам Института астрологии и психологии.

## Текущее состояние

Навигация и открытые фрагменты работают в браузере. Вход и персональные прогнозы пока не подключены к серверу: при отправке формы email не сохраняется и не передаётся. Тексты прогнозов на этом этапе статичны; перед запуском их нужно заменить актуальным контентом и подключить регистрацию.
