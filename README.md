# Сайт Анны Гриньковой

Адаптивный сайт на основе утверждённого дизайна. Сейчас работают регистрация, вход, сохранение данных рождения, каталог будущих вариантов доступа и серверная проверка прав на персональные прогнозы. Прогнозы и приём оплаты ещё не запущены.

## Локальный запуск

Нужен Node.js 24.15 или новее. Зависимости npm не требуются.

```powershell
npm start
```

Откройте `http://127.0.0.1:3000`. Данные сохраняются в `data/site.sqlite`, этот каталог не включается в Git. Порт и адрес можно задать переменными `PORT` и `HOST`. Перед публичным запуском нужен HTTPS; при `NODE_ENV=production` сессионная cookie получает флаг `Secure`.

```powershell
npm test
```

## Устройство

- `prototype/` — утверждённый дизайн и клиентский код, включая кабинет и страницу доступа.
- `server/http.js` — HTTP API и проверка авторизации на сервере.
- `server/store.js` — SQLite: пользователи, сессии, данные рождения, заказы и права доступа.
- `server/catalog.js` — уровни «День» (24 часа) и «Неделя» (7 дней, включает день).
- `test/` — проверки оплаты, возврата, сроков доступа и изоляции профилей.
- `docs/payments.md` — варианты платёжных сервисов и условия подключения.
- `docs/forecast.md` — последовательность работы над дневным прогнозом и ограничение интеграции с Sotis.

Платный доступ выдаётся только после вызова `confirmPayment` из доверенной серверной интеграции. Публичного API для такого вызова нет. До выбора сервиса и цены создание заказа отвечает `503`, а сайт прямо показывает, что оплатить пока нельзя. Эндпоинты прогноза защищены авторизацией и правами доступа, затем отвечают `501`, пока генератор не подключён.

Данные рождения сохраняются в личном кабинете, но строка города ещё не содержит проверенных координат и часового пояса. Перед астрологическим расчётом нужно нормализовать место рождения. Демонстрационные тексты на страницах дня и недели остаются статичными образцами.
