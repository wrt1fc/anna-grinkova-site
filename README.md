# Сайт Анны Гриньковой

Адаптивный дизайн сайта с открытыми фрагментами карты дня и прогноза на неделю. Основной вариант — редакционная страница с фотографиями Анны, личным разделом и переходом к полному чтению.

## Запуск

Сайт сделан на HTML, CSS и JavaScript без сборки. Из корня проекта:

```powershell
python -m http.server 4173 --directory prototype
```

Откройте `http://localhost:4173`.

## Состав

```
prototype/            сайт: HTML, CSS, JS
  assets/             изображения, используемые на сайте (портреты в WebP + JPEG)
  assets/fonts/       локальные шрифты и fonts.css
design/
  svg/                шесть экранов для импорта в Figma и эмблема Института
  preview/            PNG для быстрого просмотра
  source/             исходные портреты от заказчика без обработки
  variant-1-svg.zip   архив SVG
PRODUCT.md, DESIGN.md продуктовые и визуальные решения
local/                (не в git) архив второго варианта, записи и старые материалы
figma-export/         (не в git) скрипты экспорта сайта в SVG
```

Портреты предоставлены заказчиком. Исходники лежат в `design/source/`, а версии с тёплым тёмным фоном — в `prototype/assets/`. Эмблема и декоративные изображения подготовлены по фирменным материалам Института астрологии и психологии. Шрифты Wix Madefor Display, Roboto и Playfair Display распространяются по лицензии SIL Open Font License.

Страница задаёт Content-Security-Policy через `<meta>`: скрипты, стили, шрифты и изображения загружаются только с того же домена. При публикации на сервере стоит продублировать политику HTTP-заголовком и добавить `X-Content-Type-Options: nosniff`, `Referrer-Policy` и `frame-ancestors 'none'` (последний работает только в заголовке).

После правок CSS или JS увеличьте номер `?v=` в подключениях в `index.html`, чтобы браузеры не взяли старую версию из кэша.

## Текущее состояние

Навигация и открытые фрагменты работают в браузере. Вход и персональные прогнозы пока не подключены к серверу: при отправке формы email не сохраняется и не передаётся. Тексты прогнозов на этом этапе статичны; перед запуском их нужно заменить актуальным контентом и подключить регистрацию.
