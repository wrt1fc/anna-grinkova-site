# Метафорические карты

22 авторские иллюстрации для локального интерфейса сайта Анны Гриньковой.
Направление согласовано с пользователем: природа, глубина, мягкий свет и тёплое золото.
Созданы с помощью инструмента генерации изображений, 25 октября 2026 года.

Формат: WebP, 1024 × 1536. Изображения не содержат названий и номеров:
подписи добавляет интерфейс, сохраняя читаемость на разных экранах.
Общий размер коллекции — около 9 МБ. Страница загружает только используемые карты.
