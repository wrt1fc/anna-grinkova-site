# Источник изображений карт

В этом каталоге находятся 22 старших аркана оригинальной колоды Rider–Waite–Smith (1909), иллюстратор Pamela Colman Smith. Изображения взяты из [tarot-api](https://github.com/sixseeds/tarot-api/tree/master/cards), где автор указывает их как public domain. Статус оригинальной колоды также описан в [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck). Использованы исходные иллюстрации колоды, без современных перекрасок. Для сайта файлы уменьшены и сохранены в WebP; номера `00`–`21` соответствуют старшим арканам.
