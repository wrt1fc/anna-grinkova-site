    Установить на телефонприложение

    Приложение откроется как обычное, без адресной строки

    iPhone, Safari

    1. Нажмите «Поделиться» внизу экрана
    2. Выберите «На экран Домой»
    3. Нажмите «Добавить»

    Android, Chrome

    1. Нажмите ⋮ в углу браузера
    2. Выберите «Установить приложение»
    3. Подтвердите установку

    Компьютер, Chrome

    1. Нажмите значок установки в адресной строке
    2. Выберите «Установить»
    3. Откройте приложение с рабочего стола
