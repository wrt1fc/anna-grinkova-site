# Позже: подключение оплаты

Оплата исключена из текущего выпуска. На сайте нет тарифов, цены и оформления заказа.

Перед возвращением к этой задаче нужно выбрать платёжный сервис и создать аккаунт продавца, утвердить продукты и цены, настроить чеки и возвраты. Затем реализовать серверные заказы, проверяемые уведомления провайдера и права доступа по подтверждённым платежам. Возврат с платёжной страницы сам по себе не должен открывать доступ. Секреты провайдера хранить вне Git.
