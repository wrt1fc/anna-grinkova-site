# Локальная модель дневного прогноза

На этом ПК проверены Ollama 0.40.0 и `qwen3.5:4b` на RTX 3050 8 ГБ. Ollama распакован в `D:\AnnaAI\runtime`, модели хранятся в `D:\AnnaAI\models`. Папка с весами находится вне Git. Docker для этого запуска не нужен: нативный Ollama использует NVIDIA GPU без дополнительного слоя WSL. Вторая модель `qwen3:4b-instruct` загружена только для сравнения; рабочая настройка — `qwen3.5:4b`.

## Запуск на этом ПК

В первом PowerShell из корня репозитория:

```powershell
& .\scripts\start-local-ollama.ps1
```

В другом PowerShell:

```powershell
$env:FORECAST_LOCAL_MODEL = 'qwen3.5:4b'
npm start
```

Скрипт запуска задаёт `OLLAMA_HOST=127.0.0.1:11434`, `OLLAMA_NO_CLOUD=1`, путь к моделям и предел одной одновременно загруженной модели. Для другого ПК пути передаются параметрами `-OllamaExe` и `-ModelsPath`. Проверка доступности: `Invoke-RestMethod http://127.0.0.1:11434/api/tags`. Проверка десяти дат: `node scripts/evaluate-local-model.js qwen3.5:4b 2026-10-07 10`.

Для повторной установки на другом ПК скачайте Ollama с [официальной страницы Windows](https://docs.ollama.com/windows), задайте каталог моделей на диске со свободным местом и выполните `ollama pull qwen3.5:4b`. Не переносите веса через Git. Модель опубликована в [каталоге Ollama](https://ollama.com/library/qwen3.5:4b) с лицензией Apache 2.0.

## Что делает модель

Астрономические положения, аспекты и карту таро рассчитывает код. Модель получает только тему карты и готовый совет, без почты, профиля рождения, чисел планет, времени переходов и персональных данных. Она возвращает короткое пояснение жизненной ситуации. Код добавляет его к неизменной расчётной части; действие и вопрос остаются редакционными. Ответ с упоминанием планет, точного времени, обещанием события, вопросом вместо пояснения или обрывом отклоняется. При таймауте 45 секунд (меньше `proxy_read_timeout` в Nginx) или ошибке остаётся расчётный текст.

Предварительная манера подачи описана в `docs/forecast-voice.md`; инструкции лежат в `config/forecast-style.json`. Это настройка готовой модели, **не обучение весов на голосе Анны**. Без согласованных примеров дневных прогнозов невозможно честно утверждать, что модель пишет её авторским голосом. Персональный прогноз пока не передаётся модели.

## Результат локальной проверки

Для десяти последовательных дат с 7 октября 2026 года проверялись завершённый JSON, длина пояснения и отсутствие запрещённых фактов: автоматический фильтр принял 10 из 10. Это проверка формы и ограничений; литературное качество и астрологическую интерпретацию ещё должна оценить Анна. На прогретой модели генерация короткого пояснения занимала примерно 1–3 секунды; первая загрузка в GPU заняла около 27 секунд. Ollama показывал `100% GPU`, контекст 2048 и около 3,1 ГБ для модели. Потребление всей видеопамяти системы при одной загруженной модели было около 5,2 ГБ. На рабочем сервере время надо измерить заново.
