# Предварительный профиль подачи прогноза

Версия: `2026-10-03-preliminary`. Настройки для локальной языковой модели находятся в [`config/forecast-style.json`](../config/forecast-style.json) и автоматически передаются модулем `server/local-writer.js`, когда задан `FORECAST_LOCAL_MODEL`. Это редакционные инструкции, **не обучение весов модели**. Генеративная модель на текущем компьютере не установлена; качество её ответов ещё не проверено.

## Что наблюдается

Устная речь: контакт с аудиторией, вопросы и уточнения, объяснение через личные и бытовые ситуации, свободный переход от астрологического термина к психологическому смыслу. Она длиннее и менее структурирована, чем короткий прогноз. В эфире встречаются истории участников и резкая лексика; их нельзя переносить в публичный текст.

В последних дневных постах обычно есть конкретный астрологический факт, простое описание возможной ситуации, лёгкая ирония и несколько практических шагов под заголовком «Стратегия на день». Часто указан момент смены знака Луны по МСК. Посты заканчиваются призывом к реакции; это приём канала, который не нужен в личном кабинете. Августовские тексты заметно более эмоциональны и категоричны; для приложения выбран более сдержанный формат последних публикаций.

## Правила для приложения

1. Писать на русском, обращаться к читателю на «вы», сохранять живую и ясную интонацию.
2. Сначала назвать **только рассчитанные** знаки Солнца и Луны, фазу Луны и цифровую карту таро; затем дать одну узнаваемую жизненную ситуацию и конкретное действие на сегодня.
3. Лёгкая ирония допустима, если она не затмевает смысл. Без дословных фраз из канала, частных историй из эфира, брани, запугивания и просьб ставить реакции.
4. Не добавлять аспекты, точное время переходов и персональные выводы: нынешний расчёт их не передаёт. Не обещать события. Текст не должен выдавать цифровой выбор таро за физический расклад.
5. Поля API остаются `body`, `action`, `question`. `action` — один выполнимый шаг, `question` — один вопрос для размышления. Численные факты проверяются после ответа модели; при ошибке используется локальный редакционный текст.

Исходная запись **не добавлена в Git**: в ней есть личные сведения участников эфира. Для будущего обучения или проверки на другом компьютере нужен отдельный согласованный набор примеров без данных слушателей. До этого профиль остаётся предварительным. Перед публикацией текстов от имени Анны потребуется её редакционное согласование и проверка серии дневных прогнозов.

На временном сервере профиль попадёт вместе с кодом после получения репозитория. Чтобы включить переформулирование, отдельно установите локальный Ollama и выбранную модель и задайте `FORECAST_LOCAL_MODEL` (сейчас предложена `qwen3:4b`). Без этой переменной сайт продолжит выдавать расчётный редакционный текст. Сырые записи и веса моделей в репозиторий не входят.
