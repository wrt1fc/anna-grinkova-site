# Telegram: бот и мини-приложение

Мини-приложение открывает тот же сайт внутри Telegram. Бот отвечает на `/start` и `/help` кнопкой «Открыть приложение»; кнопка меню рядом с полем ввода делает то же самое.

## Что уже есть в коде

| Файл | Что делает |
|---|---|
| `server/telegram/init-data.js` | Проверяет подпись `initData`, которую мини-приложение передаёт со страницы. Без неё Telegram-идентификатору верить нельзя |
| `server/telegram/bot.js` | Клиент Bot API: ответы на `/start`, `/help`, настройка вебхука, кнопки меню и списка команд |
| `server/routes/telegram.js` | `POST /api/telegram/webhook` (обновления от Telegram, проверка секрета) и `POST /api/telegram/verify` (проверка `initData`) |
| `scripts/telegram-setup.mjs` | Разовая настройка после получения токена |
| `test/telegram.test.js` | Тесты подписи, бота и маршрутов |

Пока `TELEGRAM_BOT_TOKEN` пуст, все адреса `/api/telegram/*` отвечают 404, на сайт это не влияет.

## Когда будет токен

1. В Telegram откройте @BotFather → `/newbot` → имя и ник бота → скопируйте токен.
2. На сервере откройте `sudo nano /etc/anna/site.env` и добавьте (токен в чат не присылайте):
   ```
   TELEGRAM_BOT_TOKEN=токен
   ```
3. Выполните настройку: она создаёт секрет вебхука, задаёт кнопку меню и команды, затем перезапускает сайт:
   ```
   sudo bash /opt/anna-site/scripts/telegram-activate.sh
   ```
4. Откройте бота в Telegram и нажмите `/start`.
5. Для кнопки «Открыть приложение» в профиле бота: @BotFather → `/mybots` → бот → Bot Settings → Configure Mini App → Enable Mini App. URL: `https://мояфортуна.рф/`. Тот же адрес открывает кнопка меню, настроенная скриптом.

Прямая ручная проверка обработчика этого не выявляла. Доставка переключена на `https://fortuna-fi.13-143-164-147.sslip.io:88/api/telegram/webhook`. На финском VPS добавлен `deploy/fortuna-fi-webhook.caddy`, один import и правило UFW 88/tcp; для применения валидированной конфигурации выполнен restart Caddy (admin API на этом сервере отключён). Этот listener принимает только POST к вебхуку, другие запросы получают 404. Секретный заголовок передаётся российскому обработчику и проверяется там; токен бота на Финляндию не копировался. Порт 88 выбран из поддерживаемых Telegram портов, так как 443 и 8443 заняты VPN.

В `/etc/anna/site.env` сохранён `TELEGRAM_WEBHOOK_URL`. Скрипт настройки учитывает его вместо вычисления URL по `PUBLIC_URL`; основной адрес приложения не меняется. Обновлённый скрипт опубликован в активной сборке и `/opt/anna-site`. После смены Telegram действительно доставил ожидающий `/start`: запрос зафиксирован сервером с финского IP, очередь обнулилась; пользователь подтвердил появление ответа с кнопкой VPN. Ручной пробный запрос не отправлял сообщения в реальные чаты. Исходящий доступ российского сервера к Bot API по-прежнему может требовать временного защищённого маршрута при повторной настройке.

### Оформление бота

Запасная кнопка «Подключение с VPN» во всех ответах на команды открывает финский relay `https://fortuna-fi.13-143-164-147.sslip.io:9443/` (константа `VPN_APP_URL` в branding.js). Для команд разделов сохраняется соответствующий hash-маршрут. Основная кнопка, меню бота и Main Mini App остаются на `.рф`. Кнопки появляются в новых ответах бота (нужно повторно отправить `/start`); старые сообщения автоматически не редактируются. 11 ноября 2026 bot.js и branding.js обновлены в активной сборке `/opt/anna-releases/fortuna-f0df06b`, сервис перезапущен; тесты и ответы живого вебхука проверены.

Тексты профиля, приветствие, справка и команды находятся в `server/telegram/branding.js`. Скрипт настройки применяет название «МояФортуна», описание, короткое описание, семь команд, кнопку меню и аватар `prototype/assets/app/icon-512.png` (существующий золотой знак сайта). Команды открывают нужный раздел Mini App; разговор с Фортуной проходит внутри приложения.

Вебхук возвращает `method: sendMessage` прямо в JSON-ответе Telegram. Для приветствия и навигации серверу не требуется отдельное исходящее соединение с Bot API. Групповые сообщения игнорируются. Повторная настройка не удаляет накопившиеся обновления.

11 ноября 2026 оформление применено к `@myFortuna_app`. Активная сборка: `/opt/anna-releases/fortuna-f0df06b`, копия `weekly-ba70266` с патчем `f0df06b`; каталог задан в `50-weekly-calendar.conf`. Остальные drop-in настройки и модель сохранены. Прямой исходящий доступ сервера к Bot API даёт тайм-аут, поэтому разовая настройка выполнена через временный SSH reverse TCP tunnel с проверкой TLS-сертификата `api.telegram.org`. Токен оставался на сервере. Для обычных ответов через вебхук этот туннель не нужен. Для повторной настройки требуется восстановленный исходящий доступ либо такой же временный защищённый маршрут.

`prototype/miniapp/telegram-app.js` загружает официальный Telegram SDK только при запуске из Telegram. Настраивает цвета, раскрывает приложение, подключает нативную кнопку «Назад» и учитывает безопасные отступы. Подпись запуска не используется вместо существующей сессии: вход в аккаунт — через те же email и пароль, что на сайте. Токен в клиентский код не передаётся.

Дневной и недельный прогнозы доступны внутри Mini App. У действующей подписки сохраняется доступ после входа в свой аккаунт. Покупка цифровой подписки внутри Telegram требует отдельной интеграции Telegram Stars; Prodamus остаётся способом оплаты обычного сайта. До интеграции Stars кнопка покупки в Telegram показывает сообщение о недоступности и не открывает внешнюю оплату.
