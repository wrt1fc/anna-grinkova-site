# Дневной прогноз и подготовка временного сервера

**Цель:** довести дневной прогноз до проверяемого общего и персонального расчёта, подготовить речевой профиль Анны и безопасный перенос на другой компьютер.

**Текущий стек:** Node.js 24, SQLite, Astronomy Engine, обычный HTML/CSS/JavaScript. Оплата остаётся отложенной по решению заказчика.

## Решения

- Расчёты выполняются в коде. Языковая модель получает готовые факты и пишет текст, не вычисляя долготы и аспекты.
- Публичный прогноз доступен без входа. Персональный прогноз появляется только после входа и сохранения подтверждённого города, даты и местного времени рождения. Кэш персонального ответа изолирован по пользователю и дате.
- Для выбора города используется локальная выборка GeoNames `cities15000` с географическими координатами и IANA-зоной; редкие места можно указать координатами и зоной вручную. Данные GeoNames требуют атрибуции CC BY 4.0. Старое свободное поле остаётся в базе, но не считается точным местом без выбора.
- Перевод местного времени рождения в UTC отвергает несуществующее и неоднозначное время при переводе часов, пока пользователь не уточнит смещение. Для старых дат точность исторической зоны зависит от данных IANA и должна быть видна в описании результата.
- Персональная астрология первого выпуска: тропические геоцентрические долготы натальных светил и планет, аспекты текущих светил/планет к натальным положениям. Дома и дирекции не выдаются как рассчитанные.
- Таро первого выпуска: 22 старших аркана в прямом положении; для гостя одна воспроизводимая карта даты, для аккаунта отдельная воспроизводимая карта пользователя и даты. В интерфейсе это названо цифровым выбором.
- Сырые записи и расшифровки личных консультаций не попадают в Git. В Git входят только профиль речевой подачи, обезличенные авторские примеры и критерии оценки.

## Задачи и проверки

- [x] Подготовить каталог городов, поиск и явный выбор города; мигрировать схему профиля без потери старых данных. Проверить одноимённые города, ручной ввод и старый профиль.
- [x] Проверить перевод местного времени рождения в UTC на обычной дате, пропущенном и повторённом часе. Посчитать натальные долготы и дневные транзиты; добавить эталонные сверки с Sotis.
- [x] Добавить дневные события с точным временем в МСК: смену знака Луны и ближайшие точные аспекты. Проверить границы суток и угловой переход через 0°.
- [x] Включить персональный дневной ответ и личную карту таро; сохранить публичный режим и изоляцию данных. Проверить API и интерфейс.
- [x] Обработать оставшуюся часть `record.ogg`, уточнить документ речевой подачи и подготовить обезличенный набор примеров с ручным контрольным списком для будущей модели.
- [x] Добавить резервное копирование и безопасное восстановление SQLite, проверку работоспособности, CI, образец прокси с внешним лимитом, руководство по секретам и переносу. Проверить восстановление на временной базе и запуск из чистого checkout.
- [x] Запустить полный набор тестов, проверку зависимостей и Git diff; отправить все изменения в существующую ветку и PR.

## Границы результата

Реальная скорость генерации и устойчивость под нагрузкой проверяются на будущем сервере. Почтовый провайдер требует рабочего аккаунта и ключа. Платёжный провайдер не выбран, поэтому оплату не подключаем. Сервис Sotis не предоставляет документированного API для этой интеграции; локальный расчёт сохраняет работоспособность при недоступности сайта.
