# Примеры подачи для проверки модели

Это **синтетические редакционные образцы**, а не цитаты Анны и не стенограмма эфира. Подставлять в них можно только реально рассчитанные астрономические факты и цифровую карту таро. Персональные истории участников эфира здесь не использованы.

| Ситуация | Подходящая подача | Действие и вопрос |
| --- | --- | --- |
| Много мелких задач | «Смотрите, день может рассыпаться на десятки мелочей. Выберите ту, после которой остальное станет проще». | Закрыть одну важную задачу. «Что освободит мне внимание?» |
| Напряжённый разговор | «Не обязательно отвечать на первой эмоции. Пауза позволит назвать то, что вы хотите сказать на самом деле». | Записать главное перед разговором. «Что я пытаюсь объяснить?» |
| Смена планов | «План меняется. Проверьте, что из прежнего всё ещё важно, прежде чем переделывать весь день». | Отделить обязательное от переносимого. «Что действительно нельзя отложить?» |
| Перегрузка информацией | «Сообщений много, ясности мало. Дайте себе время проверить один факт». | Проверить источник важного сообщения. «На чём основан мой вывод?» |
| Нужно сделать выбор | «Если вариантов несколько, смотрите не только на быстрый результат, но и на цену каждого шага». | Выписать по одному последствию вариантов. «С чем я готова жить дальше?» |
| Возвращение к старой задаче | «Знакомая тема снова просит внимания. Возможно, сейчас вы видите деталь, которую раньше пропустили». | Проверить прежнее решение. «Что изменилось с тех пор?» |
| Хороший результат | «Остановитесь на минуту: это уже сделано. Можно признать результат без нового списка требований к себе». | Записать завершённое дело. «Что помогло его довести?» |
| Нехватка сил | «Не нужно превращать каждую паузу в ещё одну задачу. Выберите разумный темп для сегодняшнего дня». | Убрать одно необязательное дело. «Что сегодня можно упростить?» |
| Переход Луны между знаками | «До перехода может быть удобнее закончить начатое, после — взглянуть на следующий шаг». Только если расчёт содержит время перехода. | Проверить план на вторую половину дня. «Что требует другого подхода?» |
| Точный аспект | «Этот показатель можно использовать как повод заметить свою реакцию, а не как обещание события». Только если расчёт содержит аспект и время. | Наблюдать один конкретный выбор. «Как я отвечаю на эту ситуацию?» |

Контроль ответа модели: факты совпадают с расчётом; есть одна понятная ситуация, а не набор общих пожеланий; нет выдуманной биографии, гарантированного предсказания, имитации личного расклада или чужой личной истории; совет выполним сегодня; вопрос один и по теме. Перед публикацией от имени Анны нужна её оценка этой подачи.
