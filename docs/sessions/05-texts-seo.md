# Чат «Тексты и SEO»

**Модель:** Sonnet 5.5. **Рабочая папка:** `E:\ai-site-intl`.

## Как начать

> Прочитай `docs/sessions/05-texts-seo.md`. Задача: `<что нужно>`.

## Что есть

- Адреса и мета-теги: `config/seo.json` (title до 60 символов, description 140–160), отрисовка — `server/seo.js`; `sitemap.xml` и `robots.txt` генерирует сервер; Schema.org Person + WebSite.
- Подтверждение в Яндекс.Вебмастере и Google Search Console — через `YANDEX_VERIFICATION` и `GOOGLE_SITE_VERIFICATION` на сервере.
- Ключевые запросы (частотность не проверена, нужен Яндекс Вордстат):
  - главная: анна гринькова, астропсихолог, астропсихолог онлайн;
  - `/karta-dnya`: карта дня таро, карта дня онлайн бесплатно, карта таро на сегодня;
  - `/prognoz-na-nedelyu`: астрологический прогноз на неделю;
  - `/chat`: вопрос астрологу онлайн, консультация астропсихолога.
- Материал для статей: 125 вопросов аудитории с ответами в манере Анны (`D:\AnnaAI\data\dataset`) — после одобрения Анной.

## Что впереди

- Проверить запросы в Вордстате, подправить title и description.
- Страница «Об Анне»: образование, институт, опыт; контакты; страницы `/privacy`, `/terms`, `/offer` (тексты готовит юрист).
- Статьи на отдельных адресах по частым вопросам (каждую добавлять в `config/seo.json`).
- Сообщения для заказчика — коротко, без технических деталей.

## Правила

- Голос Анны: «Смотрите…», от понятия к жизненной ситуации, без обещаний и гарантий, без «ИИ» и «нейросети» в текстах для посетителей.
- Где упоминается Instagram — звёздочка и сноска про Meta.
- Название: Институт прогрессивной психологии.
- Тексты на страницах сайта правит Codex — передавать задачей в `docs/codex-ui-tasks.md`.
