# Бытовой вопрос об отоплении превращается в ответ о доходе

Запрос: выяснить, почему «почему не работает отопление» получил денежный прогноз, хотя вопрос посторонний.

Проверен действующий релиз `/opt/anna-releases/dashboard-20261111`, CHAT_LOCAL_MODEL=anna-v27, protocol19, fact guard1. Сделаны8 обычных обращений к реальной модели с действующим подбором карты/материалов, на синтетическом профиле, без истории и изменения рабочего аккаунта. Сырые ответы и итоговые замены сохранены отдельно: `D:/AnnaAI/reports/v27-offtopic-audit-20261111/responses.json`. Производственный код и конфигурация не менялись.

## Точная цепочка

1. MONEY_TOPIC в anna-method.js содержит `работ[аеуыой]` без границ слова. Это совпадает с началом слова «работает».
2. asksAboutMoney ошибочно возвращает true для отопления, крана, интернета, машины и Python-кода. chartContext добавляет натальную денежную карту, а поиск —5 денежных материалов.
3. На запрос об отоплении v27 в обеих сырых попытках правильно отвечает утверждённым отказом: «Я разбираюсь в астрологии… С этой темой не помогу…».
4. incompleteMoneyExplanation трактует этот отказ как неполное объяснение денежного дома: отсутствуют имена/дома всех управителей. Запускается лишний повтор с указанием перечислить управителей.
5. После второго правильного отказа сервер публикует calculatedMoneyExplanation. Итог model=null, groundedFallback=true, explanationFiltered=true. Получается вводная «Возможные темы заработка…» со скриншота.

## Дополнительные воспроизведения

- «Почему не работает кран/интернет/машина/код на Python?» — тот же денежный fallback.
- «Почему сломался чайник?» — денежная карта не передана, правильный отказ остаётся финальным.
- «Почему не работает вход в личный кабинет Фортуны?» — тоже ошибочный денежный fallback. Дополнительно модель сама отказывает по разрешённой сервисной теме; её необходимо отличать от бытовой посторонней темы.
- «Какую профессию мне выбрать?» — денежный/карьерный контекст действительно релевантен; эта положительная ветка должна сохраняться после исправления.

Из8 обращений6 попали в ошибочный денежный fallback; это5 бытовых/технических вопросов и1 вопрос о самом сервисе. Один бытовой вопрос с другим глаголом правильно отклонён, один карьерный обработан по теме.

## Требуемое исправление

Распознавать трудовую деятельность по смыслу и словоформам, не по подстроке «работа» внутри «работает». Решение о допустимой теме принимать раньше добавления личной карты и требований денежной полноты. Корректный отказ не прогонять через проверки полноты доходного объяснения и не заменять доходным fallback. Сохранить разрешённые темы приложения и приоритет срочных/кризисных запросов. Добавить бытовые переформулировки, сервисные обращения и положительные карьерные контроли.

Это диагностика с реальными ответами, не отчёт об исправлении. В данном случае исходный отказ v27 был верным; неверный окончательный ответ сформировал сервер.
