# Очистка старых моделей — 14.11.2026

После отдельной проверки пользователь подтвердил удаление тяжёлых артефактов v20–v26 с сохранением адаптеров, контрольных точек, обучающих данных и отчётов.

## Удалено

- Восемь тегов Ollama: anna-v20, v21, v22, v23, v24, v24-t0, v25, v26. Использован API удаления моделей, общие blobs вручную не удалялись.
- Семь дополнительных anna-v20…v26-q8_0.gguf в соответствующих папках обучения.
- Пять промежуточных каталогов: natal-training-v20-r4/merged-v20, natal-training-v21-r1/merged-v21, natal-training-v24-r1/merged-v24, natal-training-v25-r2/merged-v25, natal-training-v26-r2/merged-v26.

В v11–v18 готовых установленных моделей не было; небольшие файлы подготовки, адаптеры и история этих версий сохранены. Общие серии v12–v14 не удалялись. Серверные инструкции с историческими номерами версий сохранены.

## Проверки и результат

Перед удалением подтверждены anna-v27 в рабочем процессе сайта, отсутствие загруженных удаляемых моделей, открытых файлов в удаляемых каталогах и обнаруженных процессов обучения. Пути удаления разрешены строго внутри заранее перечисленных каталогов.

После удаления проверены размеры, inode и mtime всех3759 сохраняемых файлов в затронутых папках. Digests всех17 оставшихся тегов Ollama не изменились. Сохранены v10, v19, v27–v31 и остальные модели вне согласованного диапазона. Рабочий release остался server-contract-20261113, модель anna-v27. Выполнена реальная генерация Ollama v27, публичные /api/health и /chat вернули HTTP200. Код приложения, база пользователей и настройки не изменялись.

Освобождено100,50ГиБ, доступно119,02ГиБ. Заполнение корневого раздела снизилось с96% до74%.

Закрытый журнал: /etc/anna/backups/model-cleanup-20261114T021917Z. В нём сохранены plan.json, определения удалённых моделей, execution.json и result.json. Это журнал и копии определений, а не резерв удалённых весов. Для повторного включения старых моделей потребуется пересборка из сохранённых адаптеров и базовой модели.
