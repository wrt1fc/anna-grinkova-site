# Чат «Быстрые вопросы»

**Модель:** Haiku 5.5 — самая дешёвая. Для коротких вопросов: «что выбрать в панели», «куда нажать», «что значит этот пункт». Если нужно менять код или решение сложное — перейти в профильный чат.

## Как начать

> Прочитай `docs/sessions/06-quick-questions.md`. Вопрос: `<вопрос>` (можно приложить скриншот).

## Коротко о проекте

- Сайт Анны Гриньковой: карта дня, прогноз, кабинет, чат, оплата. Код — Node.js и PostgreSQL, интерфейс делает Codex.
- Хостинг: один сервер Immers.cloud (RTX 2080 Ti, Москва, Ubuntu 26.04 CUDA, локальный диск, статический IP). Копии базы — S3 Timeweb Cloud.
- Домены в Рег.ру: `мояфортуна.рф` основной, `мояфортуна.com` перенаправляет на него. Платные пакеты Рег.ру («Домен плюс», хостинг, почта) не нужны.
- Письма с кодами — Unisender Go, почтовый ящик для этого не нужен.
- Оплата позже: ЮKassa (РФ), Robokassa (иностранные карты) — после юрлица и документов.
- Расходы: сервер ~16–21 тыс. ₽/мес (дешевле с предоплатой), домены — раз в год, S3 — копейки.

## Правила ответа

- Коротко, по шагам, без технических подробностей, если не просят.
- Пароли, закрытые ключи и секреты не запрашивать. Открытый SSH-ключ показывать можно.
- Не советовать платные дополнения, которые проекту не нужны.
