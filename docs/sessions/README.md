# Чаты по направлениям

Один чат — одна задача: так контекст маленький и ответы дешевле. Общий контекст проекта лежит в `CLAUDE.md` в корне и подхватывается автоматически. Начинайте новый чат первым сообщением из раздела «Как начать» нужного брифа.

| Чат | Бриф | Модель |
|---|---|---|
| Сервер и запуск | [01-server-launch.md](01-server-launch.md) | Sonnet 5.5 |
| Модель Анны | [02-anna-model.md](02-anna-model.md) | Sonnet 5.5 |
| Сервер сайта и оплата | [03-backend-payments.md](03-backend-payments.md) | Sonnet 5.5 |
| Проверка уязвимостей и ошибок | [04-security-review.md](04-security-review.md) | Opus 5.5 |
| Тексты и SEO | [05-texts-seo.md](05-texts-seo.md) | Sonnet 5.5 |
| Быстрые вопросы | [06-quick-questions.md](06-quick-questions.md) | Haiku 5.5 |

Интерфейс делает Codex по `docs/codex-ui-tasks.md`, отдельный чат Claude для этого не нужен.

Opus включать только для сложного: безопасность, архитектура, ошибка, с которой Sonnet не справился.
