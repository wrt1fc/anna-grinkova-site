### Как всё связано

Посетитель открывает сайт или приложение в Telegram. Основной сервер проверяет аккаунт и подписку, получает данные рождения, выполняет расчёт и возвращает результат.

На основном сервере работают сайт, база PostgreSQL и Ollama - программа, которая запускает обученную Фортуну. Письма отправляет Unisender Go, оплату обычного сайта принимает Prodamus. Дизайн хранится в Figma, история кода - в GitHub.

Для Telegram используется также вспомогательный сервер в Финляндии: он передаёт команды бота основному серверу и предоставляет запасной адрес открытия приложения с VPN.

### Что есть на сайте

Натальная карта, карта дня, метафорический расклад, прогноз на неделю, чат с Фортуной, подписка и личный кабинет. Часть функций доступна после входа и оформления подписки.

## 1. Основной сервер

### Где находится рабочий сервис

Основной сервер размещён у Immers.cloud в России. На нём работают приложение сайта, PostgreSQL, Ollama и Nginx. Nginx принимает защищённые подключения и передаёт запросы приложению. PostgreSQL хранит записи, а Ollama формирует текстовые ответы с переданным ей контекстом.

| Что нужно найти | Где искать на сервере |
| --- | --- |
| Управление сайтом | Служба anna-site в systemd |
| Опубликованные версии | Каталоги в /opt/anna-releases/ |
| Базовый каталог проекта | /opt/anna-site; действующая служба может запускать другую сборку |
| Основные настройки и ключи | /etc/anna/site.env |
| Дополнительные настройки запуска | /etc/systemd/system/anna-site.service.d/ |
| Настройки выбора Фортуны | Отдельные файлы окружения в /etc/anna/, подключённые к службе |
| Журнал работы приложения | Журнал службы anna-site |
| Состояние сайта | [Проверка /api/health](https://xn--80axddamoif3i.xn--p1ai/api/health) |

Опубликованную папку определяют по действующим настройкам службы. Она может меняться при обновлении. Поэтому перед правкой специалист проверяет, какую сборку сейчас использует anna-site.

### Где находятся данные

Аккаунты, данные рождения, доступ, заказы и сохранённая по согласию переписка находятся в PostgreSQL на основном сервере. Подключение задаётся серверной настройкой DATABASE_URL. Файлы сайта не заменяют базу данных: для переноса нужны и приложение, и отдельная копия базы.

Резервные копии предусмотрены в S3 Timeweb Cloud. Наличие свежей копии и возможность восстановления нужно проверять отдельно; этот документ не подтверждает их состояние.

### Что отвечает за расчёт и ответы

Положения планет вычисляет Astronomy Engine, правила интерпретации задаёт методика Анны. Sotis используется для дополнительной сверки. Ответ в чате формулирует обученная Фортуна через Ollama. По отчёту от 11 ноября подключена anna-v27; помощник может допускать ошибки, и проверка подключения не заменяет оценку качества.

## 2. Дизайн и изменения сайта

### Где находится дизайн

Редактируемые экраны находятся в [Figma «Анна Гринькова»](https://www.figma.com/design/BggW2QztAkK0GdWCSrHOKy/). Там согласуют расположение блоков, цвета, фотографии, кнопки и состояния экранов. Среди страниц есть «08 · Мини-приложение».

Изменение макета не обновляет сайт автоматически. После согласования специалист переносит дизайн в интерфейс, проверяет его на телефоне и большом экране, затем публикует новую сборку на сервере.

### Где искать нужную часть опубликованной сборки

Пути ниже указаны внутри действующей серверной сборки. Это ориентир для специалиста, которому передают задачу.

| Что изменить | Где находится |
| --- | --- |
| Страницы, оформление, кнопки | prototype/miniapp/ |
| Изображения и шрифты | prototype/assets/ |
| Юридические страницы | prototype/legal/ |
| Правила входа, расчётов и чата | server/ |
| Подключения оплаты | server/billing/ |
| Приветствие и команды бота | server/telegram/ |
| Цена и срок подписки Prodamus | config/prodamus.json |
| Лимиты вопросов и профилей | config/plans.json и серверная проверка доступа |
| Адреса и описания страниц для поиска | config/seo.json |
| Контекст и правила ответов | config/chat-context.json и связанные настройки чата |
| Версии юридических согласий | config/legal.json |

### Как передавать задачу

Для изменения дизайна удобно указать экран в Figma и описать желаемый результат. Для ошибки - адрес страницы, действие пользователя и ожидаемое поведение. Например: «После успешной оплаты подписка не появилась в кабинете».

Цены, лимиты и правила доступа согласуют до публикации. В старых материалах встречаются прежние тарифы: config/products.json не является источником цен текущей подписки Prodamus.

GitHub хранит исходный код и историю изменений. Отправка изменений в GitHub и публикация на сервере - отдельные операции.

## 3. Сервисы и кабинеты

### Домены и размещение

| Сервис | Для чего нужен |
| --- | --- |
| [Рег.ру](https://www.reg.ru/) | Домены мояфортуна.рф и мояфортуна.com; настройки направления доменов на сервер |
| [Immers.cloud](https://immers.cloud/) | Основной российский сервер сайта, базы и Фортуны |
| [Timeweb Cloud](https://timeweb.cloud/) | Предусмотренное хранилище резервных копий S3 |
| [Figma](https://www.figma.com/) | Макеты и согласование оформления |
| [GitHub](https://github.com/wrt1fc/anna-grinkova-site) | Исходный код и история изменений |

Основной адрес - мояфортуна.рф. Дополнительный домен мояфортуна.com по принятой схеме должен перенаправлять на него; перенаправление при подготовке документа не проверялось.

### Почта и оплата

| Сервис | Как используется |
| --- | --- |
| [Unisender Go](https://go.unisender.ru/) | Основной отправитель кодов подтверждения и восстановления пароля; по отчётам настроен |
| [Brevo](https://www.brevo.com/) | Предусмотрен для зарубежных почтовых ящиков; по отчётам ключ не задан |
| [Prodamus](https://prodamus.ru/) | Оплата подписки на обычном сайте; по отчётам тестовый режим выключен |
| [ЮKassa](https://yookassa.ru/) и [Robokassa](https://robokassa.com/) | Ранее подготовленные подключения; текущая схема подписки описана через Prodamus |

По отчётам за 11 ноября подписка стоит 990 рублей за 30 дней или 2070 рублей за 90 дней. Доступ включает основной профиль и одного близкого человека, 30 вопросов за календарный месяц по московскому времени и до пяти раскладов в день. У периода на 90 дней счётчик вопросов обновляется отдельно каждый календарный месяц.

После оплаты Prodamus присылает уведомление серверу. Доступ выдаётся после проверки уведомления, а не только после перехода на страницу успеха. Реальный платёж в рамках подготовки этого документа не проводился.

Для изменений специалисту нужны права в соответствующем кабинете. Пароли, платёжные ключи и токены бота в документ не включаются.

## 4. Telegram и обслуживание

### Как устроен Telegram

Бот [@myFortuna_app](https://t.me/myFortuna_app) открывает мини-приложение с разделами сайта. Вход выполняется через аккаунт сайта; автоматический вход по Telegram пока не подключён.

Действующая подписка доступна после входа в тот же аккаунт. Покупка внутри Telegram отключена до отдельного подключения Stars. Prodamus используется для оплаты обычного сайта.

Вспомогательный сервер в Финляндии передаёт команды Telegram основному российскому серверу и даёт запасной маршрут открытия приложения с VPN. По отчётам токен бота на вспомогательный сервер не копировался. Поэтому при сбое бота нужно проверить оба сервера и доставку команд между ними.

### Куда смотреть при проблеме

| Что случилось | Что проверяет специалист |
| --- | --- |
| Сайт не открывается | Домен в Рег.ру, доступность Immers.cloud, Nginx, служба anna-site |
| Не приходит код на почту | Unisender Go, настройки отправителя, дневная квота и журнал сайта |
| Оплата прошла, доступа нет | Заказ в Prodamus, доставка уведомления, его проверка и запись в базе |
| Фортуна не отвечает | Ollama, выбор версии помощника, занятость и журнал приложения |
| Бот не отвечает на /start | Telegram, финский промежуточный сервер, обработчик на основном сервере |
| Дизайн не совпадает с Figma | Согласованный экран и версия, опубликованная на сервере |
| Нужно восстановить данные | Свежесть резервной копии и проверенное восстановление PostgreSQL |

### Как обновлять проект

Сначала согласуют изменение, затем готовят и проверяют новую версию. Перед публикацией сохраняют возможность возврата к предыдущей сборке; при изменениях базы проверяют совместимость и резервную копию.

После публикации проверяют нужный пользовательский сценарий: открытие страницы, вход, письмо, ответ чата или оплату - в зависимости от задачи. Ответ /api/health показывает доступность сервиса, но не подтверждает работу всех подключений.

### Что хранить у владельца проекта

Доступ к Рег.ру, Immers.cloud, Figma, GitHub, почтовому и платёжному сервисам, Telegram-боту и хранилищу копий. Для каждого сервиса полезно знать владельца аккаунта, способ восстановления доступа и ответственного специалиста.

Актуальные цены, выбранная версия Фортуны, активная серверная сборка и наличие пригодных копий со временем меняются. Перед важными изменениями их сверяют с сервером и соответствующими кабинетами.
