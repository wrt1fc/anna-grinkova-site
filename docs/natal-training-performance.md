# Проверка скорости anna-v4, 25.10.2026

На RTX 3050 8 ГБ исходный запуск с пределом 3400 токенов занимал
около 50 минут на шаг (8 примеров с накоплением градиентов).
Счётчики Windows показывали около 4,6 ГБ общей GPU-памяти процесса.

Подготовка PEFT переводит неквантизованные параметры в FP32, включая
большую замороженную таблицу токенов. Флаг `--frozen-embedding-bf16`
возвращает только эту таблицу в BF16 после создания тренера. Флаг
требует поддержки BF16 и запрещает изменение обучаемой таблицы.
Нормализация и параметры LoRA остаются без изменений.

Проверки на отдельных копиях адаптера anna-v3:

- Лимит 2048 исключил оба выбранных длинных натальных примера:
  после обрезания не осталось токенов ответа. Такой способ ускорения отклонён.
- Полная длина, BF16 для замороженной таблицы: 32,29 и 24,98 секунды
  на два последовательных шага по одному примеру; loss 1,695.
- Полная длина, накопление по 8 примерам: 254,77 секунды на шаг,
  пиковое выделение CUDA 6,35 ГиБ, loss 1,741. Общая GPU-память Windows
  во время прогона составляла около 0,26 ГБ.

Данные теста — повторение двух длинных натальных примеров, а не весь набор.
Это подтверждает работоспособность и ускорение выбранной настройки,
но не гарантирует время каждого шага или качество итоговой модели.
После полного обучения требуются контрольные натальные и чат-прогоны.
Исходные карточки, полные ответы и предел 3400 токенов сохранены.
Тестовые адаптеры не используются как итоговая модель.
