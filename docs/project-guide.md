## Как всё связано

Посетитель открывает сайт в браузере или мини-приложение в Telegram. Запрос приходит на сервер проекта. Сервер проверяет аккаунт и доступ, берёт сохранённые данные рождения, выполняет расчёт и возвращает результат.

Для ответа в чате сервер также обращается к Ollama — программе, которая запускает обученную версию Фортуны. Для писем используется Unisender Go. При покупке пользователь переходит на страницу Prodamus; доступ выдаётся после проверенного уведомления от платёжного сервиса.

Основной сервер находится в России. По принятой схеме на нём вместе размещены сайт, PostgreSQL и Ollama. Telegram также использует вспомогательный сервер в Финляндии для доставки команд бота и запасного открытия приложения с VPN. Он описан в [документе о Telegram](telegram.md). Поэтому утверждение «весь трафик проходит только внутри России» не описывает текущую схему целиком.

Материалы для обучения и справочные тексты хранятся отдельно от публичного кода. Локальная папка для работы с ними — `D:\AnnaAI`. Копировать её в GitHub не нужно.

## Подписка и оплата

На дату проверки в рабочем каталоге указаны:

| Срок доступа | Цена |
| --- | --- |
| 30 дней | 990 ₽ |
| 90 дней | 2070 ₽ |

Текущая подписка предусматривает основной профиль и одного близкого человека, 30 вопросов в чате за календарный месяц и до пяти раскладов в день. Месячный счётчик вопросов обновляется первого числа по московскому времени. У подписки на 90 дней лимит отдельный для каждого календарного месяца.

Оплата на обычном сайте проходит через Prodamus. Сам переход на страницу «успешно» не подтверждает покупку: сервер должен получить и проверить уведомление об оплате. Тестовый режим на 1 ₽ выключен. Наличие настроек оплаты не заменяет проверку реального платежа.

В Telegram покупка подписки пока отключена. Пользователь с действующей подпиской может пользоваться доступом после входа в тот же аккаунт. Для покупки внутри Telegram запланирована отдельная интеграция Stars.

Текущие продукты находятся в `config/prodamus.json`, ограничения доступа — в `config/plans.json`. Старый файл `config/products.json` содержит прежние черновые тарифы, поэтому брать из него актуальные цены нельзя. Подробности — в [документе о действующей оплате](subscription-live-payments.md).

## Где хранятся данные и как устроен вход

Аккаунты, данные рождения, доступ и другие сведения сайт хранит в PostgreSQL — базе данных на сервере проекта. Для локальной разработки используется PGlite: разработчик может запустить проект без отдельной установки PostgreSQL. Локальная база находится в `data/pglite` и не передаётся в GitHub.

Подтверждение почты и восстановление пароля используют коды из писем. Основной отправитель сейчас — Unisender Go. Brevo предусмотрен кодом, но на дату проверки не настроен.

В мини-приложении используется существующий вход в аккаунт сайта. Автоматический вход по Telegram ещё не подключён. Работа с историей переписки и согласиями описана в [документе о базе](database.md); тексты и версии согласий находятся в `config/legal.json`.

Для резервных копий принято использовать S3 Timeweb Cloud. Их расписание и возможность восстановления нужно проверять отдельно при обслуживании: наличие плана резервного копирования ещё не подтверждает наличие свежей пригодной копии.

## Где что лежит в проекте

Пути в таблице отсчитываются от корня проекта — папки `E:\ai сайт`.

| Папка или файл | Что там находится | Когда туда смотреть |
| --- | --- | --- |
| `prototype/` | Страницы, стили, кнопки, изображения и поведение сайта | Нужно изменить внешний вид или действия на странице |
| `prototype/miniapp/` | Интерфейс мини-приложения и его связь с Telegram | Нужно изменить работу приложения внутри Telegram |
| `design/` | Дизайнерские материалы, изображения и экспорты | Нужны исходные визуальные материалы |
| `server/` | Серверная логика: вход, расчёты, чат, доступ и оплата | Нужно изменить правила работы сервиса |
| `server/billing/` | Подключения платёжных сервисов | Нужно разобраться с оплатой |
| `server/telegram/`, `server/routes/telegram.js` | Команды бота и обработка запросов Telegram | Нужно изменить приветствие или открытие приложения |
| `server/db.js`, `server/schema.js`, `server/store*.js` | Подключение, структура базы и работа с сохранёнными данными | Нужно изменить хранение данных |
| `config/` | Настройки тарифов, разделов, текстов и правил | Нужно найти настройку без поиска по всему проекту |
| `config/seo.json` | Адреса страниц, заголовки и описания для поиска | Нужно изменить название или описание страницы в поисковиках |
| `training/` | Подготовка обучения и проверки качества ответов | Нужно работать над следующей версией Фортуны |
| `scripts/` | Служебные команды для обслуживания | Нужно выполнить техническую операцию |
| `deploy/` | Примеры настроек запуска на сервере | Нужно восстановить или перенести сервис |
| `test/` | Автоматические проверки | Нужно проверить изменения до публикации |
| `docs/` | Инструкции и отчёты по направлениям | Нужно разобраться в конкретной части проекта |
| `docs/sessions/` | Задачи и результаты отдельных этапов | Нужно передать работу в другой чат |
| `PRODUCT.md`, `DESIGN.md` | Продуктовые и визуальные решения | Нужно понять исходный замысел |

Файлы на компьютере и активная сборка на сервере могут различаться. На момент проверки сайт запущен из `/opt/anna-releases/dashboard-20261111`. Рабочие пароли и ключи находятся отдельно от кода, в серверных файлах настроек; их содержимое не публикуется.

## На чём написан сайт

Эта часть нужна разработчику или специалисту, который будет принимать проект.

| Технология | Роль | Сайт |
| --- | --- | --- |
| HTML, CSS и JavaScript | Страницы, оформление и действия в браузере | [Справочник MDN](https://developer.mozilla.org/ru/docs/Web) |
| Node.js | Запуск серверного кода; в проекте указана версия от 24.15 | [nodejs.org](https://nodejs.org/) |
| PostgreSQL | Основная база данных | [postgresql.org](https://www.postgresql.org/) |
| PGlite | Локальная база для разработки и тестов | [pglite.dev](https://pglite.dev/) |
| Nginx | Принимает внешние подключения по HTTPS и передаёт запросы приложению | [nginx.org](https://nginx.org/) |
| Ubuntu и systemd | Операционная система сервера и управление службами | [ubuntu.com](https://ubuntu.com/), [systemd.io](https://systemd.io/) |

Сайт написан без React, Next.js и других подобных фреймворков. Для локального запуска после установки зависимостей используется `npm start`, для проверок — `npm test`. Запускать команды нужно из корня проекта. В этой рабочей папке есть вложенные материалы обучения, поэтому для проверки основного приложения можно явно указать `node --test ./test/*.test.js`, чтобы не захватывать тесты из посторонних вложенных копий.

Сайт также подготовлен к установке на главный экран телефона как веб-приложение (PWA). Это не отдельная публикация в App Store или Google Play.
