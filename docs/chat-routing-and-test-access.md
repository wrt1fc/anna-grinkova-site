# Вопросы чата и тестовый безлимит — 31.10.2026

## Распознавание вопросов

Проверены 34 личные формулировки и 13 контрольных вопросов. Исправлены пропуски: «Что означает мой Сатурн?», «Расскажи о моей Венере», «В чём мои сильные стороны?», «Почему я ревную?», «Когда я встречу любовь?», «Чем мне лучше заниматься?», «А что с работой?», «Что означает мой седьмой дом?».

Для личных вопросов учитываются формы местоимений, житейские темы и названия планет. «Работой» распознаётся вместе с «работа». Исправлена граница кириллического слова в распознавании домов; обычный вопрос об утеплении дома не считается натальным.

Короткие уточнения («А подробнее?», «Почему так?», «Можно пример?») наследуют последний вопрос пользователя. Полноценный новый вопрос этого не делает. Уточнение карты дня сохраняет прогноз, уточнение натальной карты — расчёт карты. Вопросы о ревности или доверии не превращаются автоматически в новый портрет идеального партнёра.

На реальных генерациях обнаружены выдуманные аспекты, в частности трин Солнца и MC вместо рассчитанного соединения. Добавлена проверка явных утверждений о знаках, домах, углах и аспектах. Она использует отдельные неизменяемые факты расчёта, не добавляемые в сериализованный промпт. Ошибочная генерация повторяется один раз до публикации; затем доступно рассчитанное пояснение. Это проверка поддерживаемых формулировок, а не полное понимание любого русского текста; сравнения двух людей и явно обозначенные транзитные/дирекционные утверждения требуют отдельного разбора и не смешиваются с натальными аспектами одного человека.

## Тестовые аккаунты

Миграция 4 добавляет `users.chat_unlimited`, по умолчанию `FALSE`. Флаг устанавливается оператором в базе. Адрес или редактируемое имя `test1` сами по себе не дают привилегию. Регистрация и API профиля не могут её назначить.

Управление: `DATABASE_URL=… node scripts/set-test-chat-unlimited.mjs`; отключение — с `--disable`. Утилита атомарно меняет только существующие подтверждённые аккаунты `test1@anna.test`, `test2@anna.test`, `test3@anna.test`; если отсутствует хотя бы один, изменений нет. Секрет подключения передаётся окружением службы и не печатается.

Для этих аккаунтов обходится дневной лимит обычного чата. Старые счётчики не обнуляются и не уменьшаются при ошибках неучтённых запросов. Ограничения частоты, один активный ответ на аккаунт, общая очередь и ограничения тарифа на близких людей/отдельные расклады сохраняются.

API плана возвращает `unlimitedChat: true`, `dailyChatMessages: null`; интерфейс показывает «Безлимитные вопросы» на главной, в чате и профиле. Правило не меняет цены или оплату подписки.

Проверки: 243 серверных теста, браузерные сценарии на 320–1920 px. Они включают маршрутизацию, наследование темы, защиту от подделки флага, сохранение лимита обычного аккаунта, возврат лимита после отключения, отсутствие ложного возврата квоты, отображение и изоляцию после смены аккаунта. На серверной anna-v10 проверены шесть запросов; пять ответов прошли проверку после генерации, один получил рассчитанное пояснение после повторной неудачи.
