# anna-v20 — исправления после подключения v19

Пользователь явно разрешил запуск следующей попытки 2026-11-05.
Production остаётся anna-v19 с прежней манерой общения и проверкой фактов.
Кандидат автоматически не подключается; learned invitations выключены на сайте.

Одна попытка продолжения адаптера anna-v19, одна эпоха LR3e-6, rank16,
batch1, grad_accum8, half_embedding. Не автоматическое повторение старых весов
на том же наборе: добавлены94 новые формулировки по ручному разбору ошибок.
Всего1025 train,246 открытых development eval. Все80 натальных учителей
сохранены полностью, прежние931 train не изменены.32 открытых контроля v19
остаются вне SFT; отдельно добавлены24 новых контроля, итого56.
Новые вопросы не копируют дословно прежние проверочные вопросы. Старый набор
содержит повторяющиеся формулировки при разной истории; это не объявляется
новой независимой выборкой. Новые24 — переформулировки знакомых понятий,
а не экзамен неизвестных концепций.

Исправления: модальности/стихии и Козерог, дом/знак/диспозитор, узлы и ASC/DSC,
Луна и её обитель, солнечная дуга/прогрессии, орбис и граница допуска,
релокационный UTC-инвариант, соседи/третий дом, неподтверждённые положения
карты, отсутствие выдуманных требований приложения, точный смысл разделов
о влечении/чуткости/релокационном Марсе. Отдельно — явные отказы от занятий,
нейтральное обращение при неизвестном поле и различие дневного/недельного.

Короткий system18, reference19, style19 и61 выбранный раздел методичек
сохранены, как у v19. Прежняя манера: на ты, тепло, просто, на равных,
без повторного приветствия и рекламы, без юмора в серьёзных темах.
Все новые ответы — синтетические draft, не утверждённые Анной.
Справочник не равен полному освоению всех присланных материалов.

Parent /home/ubuntu/natal-training-v19/anna-v19, adapter SHA256

Приватный набор: D:/AnnaAI/data/dataset/repair-v20-run-final.

Max_length3400, reserve32, reject_truncation=true, enable_thinking=false.
CPU token/prefix audit до GPU; реальные labels проверяются до первого шага:
prompt=-100, completion сохранена.10 шагов smoke на двух длинных примерах,
PASS allocated<9GiB/reserved<9.6GiB. Smoke-веса дальше не используются.

На сервере одна GPU и теперь живой чат. Останавливать anna-site нельзя.
Отдельная CPU-only Ollama на11435 проверена на5 вопросах тем же runtime v19:
все ответы с model=anna-v19, без fallback и в пределах45-секундного таймаута.
Проба остановлена. На время smoke/train основной Ollama временно получает
runtime override /run/systemd/system/ollama.service.d/80-anna-v20-cpu.conf:
CUDA_VISIBLE_DEVICES=-1, OLLAMA_NUM_PARALLEL=1, CPU0–5. Это может замедлить
ответы и очередь; CPU работа не равна доказанной прежней пропускной способности.
Переключение требует короткого перезапуска Ollama, сам сайт не останавливается.
После первого smoke-шага проверяется реальный CPU-ответ под нагрузкой;
неуспех/таймаут останавливает попытку до полного обучения.
Общий cgroup сначала ограничен8GiBRAM, перед CPU merge —13GiB после возврата
обычного GPU serving. На сервере16GiBRAM,5.5GiBзаняла CPU-проба.
EXIT trap и отдельный ExecStopPost восстанавливают только свой временный
override и Ollama даже при аварии. site.env и постоянные настройки не меняются.

Свежие baseline v10 и parent v19 выполняются тем же кодом, справочником и
ANNA_EVAL_DATE=2026-11-02. Runtime fact guard при сравнении весов выключен:
его повтор/запасной текст не должен скрывать недостатки модели.
Baseline v10 не обучен протоколу учебных маркеров: строгие баллы не следует
считать чистым сравнением знаний. Основной новый ориентир — parent v19.
Оценщик сохраняет raw attempts, фильтрацию, fallback, сигнал и каждую ошибку.
Отдельно применяется ограниченный аудит известных фактических паттернов к
ответам и raw; это не полный смысловой судья. Сырые старые отчёты не меняются.

индивидуальные регрессии к обоим baseline, ложные FAIL и ошибки PASS,
