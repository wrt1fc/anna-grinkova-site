# Дневной календарь и недельный разбор

- `/api/forecast/week` — семь прогнозов текущей недели и рекомендации по периодам лунных знаков. Для пользователя с разрешённым профилем рождения — личные дневные расчёты; для гостя — общие.
- Неделя: понедельник–воскресенье, граница по `Europe/Moscow`. Результат стабилен внутри недели и сбрасывается в понедельник; изменение данных рождения обновляет личный расчёт.
- `/api/forecast/day?date=YYYY-MM-DD&draw=0` — расчёт на выбранный день текущей недели. Невозможные, повторные и выходящие за неделю даты отклоняются с 400. Ответ всегда содержит выбранную дату и `calculatedFor`.
- Выбор даты в календаре обновляет карточку дня. Стрелки, Home и End доступны с клавиатуры; кнопка под карточкой открывает полный дневной прогноз на выбранную дату.
- В интерфейсе добавлены вопрос к себе, события неба со временем и переход в чат с контекстом выбранного дня/недели.

Недельный текст формируется по правилам из расчётов Astronomy Engine и уже используемых лунных тем. Он не выдаётся за текст, написанный моделью, не расходует вопросы чата и не требует отдельного запуска генерации. Рекомендации не предсказывают события и не назначают «счастливые» даты. Расчёты на полдень не подменяют точные моменты смены знака: они отдельно показаны в дневных событиях.
