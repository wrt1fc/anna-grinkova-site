# Совместимость соединения с сайтом

11 ноября 2026 пользователь прислал ошибки Chrome `ERR_HTTP2_PING_FAILED` для CSS, JavaScript и изображений при открытии сайта из США (также белый экран на Android и Windows). Независимые американские HTTP-проверки до изменения получали 200, поэтому общая недоступность домена не подтверждена; точное место сбоя HTTP/2 в пользовательской сети не установлено.

В `/etc/nginx/conf.d/anna.conf` убран параметр `http2` у всех трёх HTTPS listener: используется `listen 443 ssl;`. HTTPS, сертификаты и адреса не менялись. Проверены `nginx -t`, безопасная перезагрузка конфигурации, ALPN `http/1.1`, API health и браузерные сценарии 360/390/1440/1920 px. Требуется повторное открытие у пострадавшего пользователя для подтверждения устранения именно его сбоя.

Копия предыдущей конфигурации: `/etc/nginx/anna.conf.before-http1-20261111` (вне `conf.d`, не подключается nginx). Для отката скопировать её в `/etc/nginx/conf.d/anna.conf`, выполнить `sudo nginx -t` и только при успешной проверке `sudo systemctl reload nginx`.

Шаблон `deploy/nginx.example.conf` также использует HTTPS без HTTP/2, чтобы последующее развёртывание не вернуло настройку незаметно.
