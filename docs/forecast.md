# Дневной прогноз: расчётная модель

## Что работает

`GET /api/forecast/day` использует текущую календарную дату в `Europe/Moscow`. Без входа он выдаёт общий прогноз. После входа и сохранения однозначного времени и места рождения выдаётся персональный расчёт. [Astronomy Engine](https://github.com/cosinekitty/astronomy) версии 2.1.19 (MIT) рассчитывает геоцентрические тропические долготы Солнца, Луны и восьми планет. Натальные положения берутся на момент рождения с историческим часовым поясом; транзиты — на 12:00 МСК. Дневные события включают смену знака Луны и точные аспекты выбранных пар планет с временем в МСК. Аспекты транзитов к натальным положениям выбираются с орбом до 3°. Дома, асцендент и дирекции сейчас не рассчитываются.

Пять закрытых позиций на главной получают пять разных старших арканов из 22 по SHA-256. Для гостя выбор зависит от даты и позиции, для аккаунта дополнительно от его идентификатора. `GET /api/forecast/day?draw=0..4` возвращает прогноз именно выбранной позиции; без параметра используется первая. Это воспроизводимый цифровой выбор, а не физическая вытяжка карты. Общий текст составляет локальный редакционный модуль; при `FORECAST_LOCAL_MODEL=qwen3.5:4b` локальный Ollama добавляет короткое пояснение к каждой выбранной позиции. Пояснения кэшируются отдельно, Sotis сверяется раз за день. Запрос к модели ограничен 190 выходными токенами и отправляется только на `127.0.0.1:11434`. Модель не получает численные расчёты и личные данные; факты, совет и вопрос остаются неизменными. Неподходящий ответ отклоняется, при сбое используется редакционный текст. Персональный текст пока создаётся правилами. Модель установлена и проверена на этом ПК; подробности в [локальной инструкции](local-model.md). Платная облачная LLM не вызывается.

Предварительный профиль подачи по записи и публичным публикациям описан в [отдельном документе](forecast-voice.md). При запуске локальной модели он читается из `config/forecast-style.json`. Это настройка текста, а не обученная модель. Материалы Анны для полноценной редакционной настройки пока не получены.

Страница «Карта дня» получает результат из API и показывает общий либо персональный режим согласно полю `scope`. Персональные данные не попадают в общий кэш и недоступны гостю.

## Границы точности и следующий шаг

- Основной снимок неба показан на полдень по Москве; события в течение суток считаются отдельно. Для точного прогноза по часам нужна более подробная методика интерпретации.
- Место рождения выбирается из GeoNames либо задаётся координатами и IANA-поясом вручную. Пропущенный или повторённый час при переводе часов требует уточнения смещения. Старые свободные профили не считаются персональными до уточнения. Географический каталог сохранённой версии требует обновления перед масштабным запуском.
- В неделе пока остаётся прежний редакционный текст; API недели отвечает `501`.
- Персональный текст пока осторожный и фактологический. Для глубоких трактовок нужны проверенные правила интерпретации и одобрение примеров Анной. LLM будет писать по структурированным численным фактам, а не вычислять планетные положения.

## Sotis

Первый запрос прогноза за дату обращается к внутреннему `get.php` публичного веб-приложения Sotis. Сервер передаёт только дату, время 12:00 и фиксированный город Москву; имя, почта и данные рождения пользователя не отправляются. Из ответа читаются долготы Солнца и Луны. Если каждая отличается от локального расчёта не более чем на 0,2°, API возвращает `astronomy.sotis.status = "matched"` и оба значения. Если сайт недоступен, ответ изменился или расчёты расходятся, локальный прогноз остаётся доступным, а статус становится `"unavailable"`. Запрос выполняется один раз на дату на процесс и кэшируется. `SOTIS_VERIFY=0` отключает его.

Это рабочая, но предварительная интеграция: `get.php` не документирован как API. В [базе знаний Sotis](https://sotis-online.ru/knowledge/) описана работа пользователя с картами, но не опубликованы гарантия формата, лимиты и условия серверного доступа. Для устойчивого коммерческого запуска нужны API/условия доступа от Sotis или согласованный экспорт. Поэтому Sotis сейчас служит проверкой численных фактов, а основной расчёт выполняется локально.

Первую сверку уже добавили в тест: на [примерной карте Sotis](https://sotis-online.ru/?chr=dt:20260928104154;sx:m;cid:2729045;name:New%20chart) для 28.09.2026 10:41:54 (+03:00) Солнце показано как 5°12′30″ Весов, Луна — 25°56′07″ Овна. Локальные долготы отличаются менее чем на 0,02°; это проверяет два тела в один момент времени, но не заменяет полноценный набор эталонных карт.
