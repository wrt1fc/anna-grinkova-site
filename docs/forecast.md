# Персональный прогноз: следующий этап

Цель первого запуска — прогноз на один день, основанный на астрологических данных и таро. Неделя следует после проверки дневного результата.

## Расчёт и текст

1. Дата, точное местное время и место рождения уже сохраняются в кабинете. Перед расчётом город нужно сопоставить с координатами и часовым поясом на дату рождения; один лишь текст города недостаточен.
2. Отдельный расчётный модуль получает положения небесных тел и аспекты численным алгоритмом. Языковая модель не выполняет эти вычисления.
3. Вход для генератора текста — проверенные расчётные факты, карта таро и правила трактовки. Выход — структурированный прогноз с указанием, на каких фактах основана каждая часть. Стиль Анны можно добавить после получения её материалов.
4. Для языковой части сначала проверяется одна русскоязычная модель на реальных примерах. Цепочка «астрологическая Mistral → Qwen переводчик» увеличит задержку и число возможных ошибок; её стоит проверять только сравнительным тестом качества, а не принимать как базовую архитектуру заранее.

## Sotis

Пользователь хочет, чтобы запрос прогноза автоматически обращался к Sotis. Публичная [база знаний Sotis](https://sotis-online.ru/knowledge/) описывает построение карт в интерфейсе и обмен базами, но не даёт документированного API для получения расчётной таблицы. Ссылка на карту открывает приложение, а не стабильный машиночитаемый ответ. Поэтому текущий API прогноза пока не отправляет запрос к Sotis и честно отвечает `501` после проверки прав.

Для подключения требуется подтверждённый способ получения данных: документация/API и условия использования от Sotis либо согласованный экспорт. До этого расчётный модуль можно развивать независимо и сверять его результаты с Sotis вручную на тестовых картах. Подмена сетевого обращения фиктивным запросом не даст вычисленных данных.
