# Макеты для Figma

В `svg/` находятся шесть экранов первого варианта: главная на широком и мобильном экране, главная после выбора карты (широкий и мобильный), карта дня и прогноз на неделю, а также отдельная эмблема Института. Их можно импортировать в Figma по отдельности или взять `variant-1-svg.zip`.

Фото Анны встроены в SVG как JPEG, декоративные фоны — как PNG. Текст хранится в SVG-элементах, фигуры и эмблема — векторами. При импорте Figma может заменить гарнитуры; используйте Wix Madefor Display, Roboto и Playfair Display.

`preview/` содержит PNG для быстрого просмотра. SVG статичны: переходы и форма входа работают только в HTML-версии сайта.

`source/` хранит исходные портреты заказчика без обработки. На сайте они не используются.
